# Titanic Data Analysis

## About
This project performs data cleaning and preprocessing on the Titanic dataset.

## Steps Performed
- Loaded the dataset
- Checked missing values
- Handled missing Age values using median
- Removed Cabin column
- Encoded Sex and Embarked columns
- Standardized numerical features
- Used boxplot to inspect numerical data and outliers

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
